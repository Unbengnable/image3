Eight spatial cells retain M; the auxiliary source label is 8 × M. All sixteen predicted output positions remain. Orange loss outlines now cover positions 2, 4, 5, 7, 10, 13, 15 and 16, and the MSE count is eight. The caption was updated accordingly.

The source and prediction scenes, encoder/decoder footprints, grid dimensions, pipeline routes, target route, legend and overall physical composition were preserved. The crop set expands from two rows to four rows in its existing area, and encoded-token spacing contracts to carry eight representations. Before/after files and exact XML checks are retained. The main SVG and PNG hashes match the pre-edit freeze hashes.

This is evidence that these scientific elements can be changed consistently with native XML editing and rerendering. It is not evidence of native design-editor import, easy editing by a non-programmer, independent scientific acceptance or an improved main figure.
