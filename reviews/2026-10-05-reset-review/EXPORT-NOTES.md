# 导出范围与哈希说明

本包导出最近 reset validation 的全部 103 个文件、Diffusion Policy Stage 2 目录、相关方法与来源记录、项目工作约定快照、两张实际审计参考图，并新增人工复核导航与再次复核记录。没有导出完整聊天转储、运行环境、凭据、整个参考库或整个 Zotero 库。旧三案例已在同一仓库，可从 README 进入。

PNG 与 SVG 保持本地原字节，包括初稿、科学错误、缺字草稿、语义副本和 Inkscape 失败图。本机路径只在公开文本/元数据副本中替换为 FigureCompose、WORKSPACE、LOCAL_CODEX、LOCAL_PROGRAMS 或 LOCAL_USER 标识；本地源文件没有因此改写。脚本 run.py 仅作为现有薄入口快照，不新增绘图实现。

EXPORT-MANIFEST.json 同时保存本地源哈希和公开副本哈希。已有 provenance、freeze、完整性清单中的哈希描述原始本地记录；不能把它们直接当作经路径处理后的公开元数据哈希。图像与 SVG 的两种哈希相同。新导出清单负责核对公开包。

工作快照保持导出时的结论。PROGRESS 中未包含这次推送提交号，以避免提交记录的自引用；在线发布结果另外保存到本地发布记录。原件中的有意义空白与 Markdown 换行没有因格式清理被删除。新增导航和复核记录采用普通段落、列表与表格，没有手动对齐或 DOCX。

论文原图和参考资产保留公开来源归属，仅用于复核。源方法段是科学核验上下文，不是系统新产生的科研内容。请将作者自评、独立同模型审阅、实际导出证据、人类判断分别记录，保留未验证项，不以某一 PASS 替代总体接受。
